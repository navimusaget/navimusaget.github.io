# Navi Musaget — Literary and Research Archive

Public archive: **https://navimusaget.github.io/**  
Author website and book pages: **https://navimusaget.com/**

This repository holds public archival records for the literary and research work of **Navi Musaget**, a novelist and independent researcher working with human–AI collaboration, authorship, meaning, and continuity.

The archive is not a retail storefront, certification of research claims, or substitute for the underlying primary sources.

## How this site is maintained

The site is built with GitHub Pages and Jekyll. The author-facing catalogue and scholarly records are maintained on their dedicated pages; this README is repository guidance and is **excluded from the generated website** to avoid duplicate or outdated public pages.

Archive entries distinguish publication from proposal, experiment from independently validated finding, and public orientation from protected primary records.

The original revisions of public pages remain available in Git history. Editing the current text does not erase that earlier public history.

For public contact, use the [Author and Profiles](https://navimusaget.github.io/profiles.html) page.
